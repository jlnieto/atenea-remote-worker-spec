## Context

Existing private previews already model leases, ownership, reconciliation and
retained attachments. V2 must bind the preview to `DevelopmentChange` and
exact validation, and separately persist the operator's acceptance.

Dependencies: M1 security, M2 changes, M3 artifacts and M4 validation.

## Goals / Non-Goals

**Goals:**

- Review exact source privately from Android/web.
- Retain data/DOM/visual evidence with provenance.
- Record accepted/changes-requested decision with step-up where policy needs.
- Expire and tear down runtime without losing evidence.
- Reconcile restarts/response loss idempotently.

**Non-Goals:**

- Use a preview as production or a permanent public environment.
- Infer acceptance from opening a URL or passing Playwright.
- Accept stale source/evidence.
- Let clients choose host, route, port, tunnel or runtime.

## Decisions

### 1. Review environment is ephemeral

The environment owns lease/hard expiry, runtime/allocation/route fingerprints
and state. URL/tunnel descriptors are generated by the server and private by
default. The source and validation manifest are immutable inputs.

### 2. Review decision is durable

`ReviewDecision` records actor, change, source, validation and selected
evidence manifest plus decision and timestamp. It remains after teardown but
becomes `STALE` if any bound identity changes.

### 3. Three-layer UI evidence

Visible changes require independent persistence/data proof, DOM assertions and
visual screenshots. Playwright uses finite timeouts and required viewports.
Native-only screens add Android checks without replacing web evidence when a
web surface exists.

### 4. Private route ownership

The coordinator owns tailnet route, listener and optional localhost tunnel.
Activation/renew/stop verify full identity/revision. Public sharing is outside
this change and prohibited by default.

## Risks / Trade-offs

- [Preview differs from candidate] -> bind source/runtime/image/manifest
  fingerprints and expose them in the review view.
- [URL leaks] -> private network, short lease, no token in logs/evidence.
- [Acceptance survives source change] -> transactional stale invalidation.
- [Teardown touches another runtime] -> exact full ownership or no mutation.

## Migration Plan

1. Add disabled review environment/decision schema and APIs.
2. Extend coordinator protocol and test synthetic routes/artifacts.
3. Enable one private synthetic Atenea environment under H2/H3.
4. Add Android/web review surfaces; require H6 for a real decision.
5. Observe expiry/restart/teardown before enabling normal Atenea review.

Rollback disables new activations/decisions, stops only exact owned previews,
restores the coordinator predecessor and retains environments, decisions and
artifacts.

## Open Questions

Public temporary sharing remains explicitly out of scope and would require its
own threat model and OpenSpec.
